# Company_DB-MySQL-Queries.

This repository contains a MySQL practice project demonstrating:
- database creation
- table creation
- sample data insertion
- SELECT queries
- ALTER TABLE operations such as adding, modifying, renaming, and dropping columns

## Files
- `Company_DB.SQL.txt` — SQL script with the database schema, employee records, and ALTER TABLE examples

## Purpose
This repo is intended for learning basic MySQL commands and schema changes in a simple employee database setup.
